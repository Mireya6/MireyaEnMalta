Ficha de configuración de los AVD:

-Pixel 2 (Teléfono clásico): Perfil Pixel 2 / API 28  / Resolución: 1080 x 1920 px / Densidad: 420 dpi
-Pixel 8 (Teléfono actual): Perfil Pixel 8 / API 37.2  /Resolución: 1080 x 2400 px / Densidad: 420 dpi
-Pixel Tablet (Tablet): Perfil Pixel Tablet / API 35  / Resolución: 2560 x 1600 px / Densidad: 320 dpi 


Diferencias observadas:

Los tres dispositivos presentan diferencias principalmente en el tamaño y resolución de la pantalla.
El Pixel 2 tiene una pantalla más pequeña y una resolución de 1080 x 1920 px.
El Pixel 8 tiene una pantalla más alargada, con una resolución de 1080 × 2400 px, y utiliza una versión mucho más reciente de Android (API 37.2).
La Pixel Tablet presenta una pantalla considerablemente más grande, con una resolución de  2560 x 1600 px, por lo que los elementos de la aplicacion disponen de más espacio.

En cuanto a la rotación, los tres AVD permiten cambiar las pantallas tanto en horizontal como en vertical sin ningún tipo de problema, aunque los tres dispositivos se ejecutan con diferentes tamaños de pantalla, resoluciones, densidades y versiones de Android.
